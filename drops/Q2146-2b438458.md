# 4. Strict-window certificate: no hidden boundary hypothesis

This is the most important adversarial point, and it passes in source.

The public strict predicate is

```lean
def SameWindowSign (x : PhiInt) : Prop :=
  (0 < Tr x ∧ 0 < windowComp x) ∨
  (Tr x < 0 ∧ windowComp x < 0)
```

with

```lean
Tr(a+b phi)         = 2a+b
windowComp(a+b phi) = b-3a.
```

`Ch10_SectorNormalization.lean` proves the exact identity

```lean
theorem trace_window_norm_identity (x : PhiInt) :
    Tr x ^ 2 + 3 * Tr x * windowComp x + windowComp x ^ 2 =
      -5 * PhiInt.norm x
```

and, more directly, the two boundary lemmas reduce a zero coordinate to the ramified prime `5`:

```lean
private theorem five_dvd_prime_of_trace_eq_zero ... : 5 ∣ p
private theorem five_dvd_prime_of_windowComp_eq_zero ... : 5 ∣ p
```

followed by

```lean
theorem trace_ne_zero_of_norm_eq_neg_split_prime
    {p : Nat} (hp : Nat.Prime p) (hp10 : p % 10 = 1)
    {x : PhiInt} (hnorm : PhiInt.norm x = -(p : Int)) :
    Tr x ≠ 0
```

and

```lean
theorem windowComp_ne_zero_of_norm_eq_neg_split_prime
    {p : Nat} (hp : Nat.Prime p) (hp10 : p % 10 = 1)
    {x : PhiInt} (hnorm : PhiInt.norm x = -(p : Int)) :
    windowComp x ≠ 0.
```

There is no boundary nonvanishing hypothesis supplied by the caller. It is derived from `hp`, `hp10`, and `hnorm`. If either coordinate vanished, primality plus divisibility by `5` would force `p=5`, contradicting `p % 10 = 1`.

The actual existence theorem is then

```lean
theorem exists_sameWindowSign_zpow
    {p : Nat} (hp : Nat.Prime p) (hp10 : p % 10 = 1)
    {x : PhiInt} (hnorm : PhiInt.norm x = -(p : Int)) :
    ∃ m : Int, SameWindowSign (epsZPowMul m x)
```

proved by strong induction on the integral height

```lean
sectorMeasure x = |Tr x| + |windowComp x|.
```

In an opposite-sign region, the quadratic identity forces one of two rational inequalities; multiplying by `eps` or `epsInv` either enters the strict same-sign window immediately or strictly decreases the height. This is a terminating descent, not an assumed Archimedean selection oracle.

The public-facing internal constructor is exactly

```lean
theorem exists_geometricSectorCert
    {p : Nat} (hp : Nat.Prime p) (hp10 : p % 10 = 1)
    {x : PhiInt} (hnorm : PhiInt.norm x = -(p : Int)) :
    Nonempty (GeometricSectorCert x)
```

with no additional premise.

The strict lift is also unique:

```lean
theorem GeometricSectorCert.lift_unique {x : PhiInt}
    (c d : GeometricSectorCert x) : c.lift = d.lift
```

because a nonzero unit shift of a same-window element lies in the opposite-sign region (`Ch10_OneAtom.epsZPowMul_opposite_of_ne_zero`). So the public `SectorCert` used in iota is not arbitrary labeling once it comes from a `GeometricSectorCert`.

The genuine exceptional boundary is exactly `p=5`, and it is outside the public theorem. For example `(a,b)=(1,-2)` has norm `-5` and `Tr=0`. A theorem for *all* primes would therefore need an explicit `p ≠ 5` condition, but `p % 10 = 1` already provides that exclusion. No extra public boundary hypothesis is missing.
